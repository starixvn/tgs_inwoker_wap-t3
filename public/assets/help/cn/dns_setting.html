设定DNS服务器

Windows 7&8 设定DNS server

步骤一、在工具栏，网络按右键

步骤二、接着点击“开启网络和共享中心”

步骤三、在网络和共享中心，点击左边的"更改适配器设置"

步骤四、画面会列出你所有的网络卡和联机设定

步骤五、如果你是透过路由器或是DHCP连线的，请在接网路线的适配卡按右键并点选属性，至于PPPoE等一下会提到

步骤六、在内容可以看到各种网路功能，选取IPv4之后点一下属性

步骤七、进入IP和DNS的设定窗口，把DNS改成手动输入，填入你DNS服务器IP，确定之后就完成了 首选DNS服务器使用:8.8.8.8 备用DNS服务器使用:8.8.4.4

步骤八、PPPoE(拨号上网)的用户，请回到适配卡设定，对着拨号设定按右键>>属性， 切换至"网络"标签，一样的，选取IPv4，然后属性

步骤九、把DNS改成手动输入，填入你DNS服务器IP，确定之后就完成了， 首选DNS服务器使用:8.8.8.8 备用DNS服务器使用:8.8.4.4
